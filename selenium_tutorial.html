📚 What is Selenium?

Selenium is a powerful open-source automation framework used to automate web browsers. It allows you to programmatically control browsers to perform tasks like testing web applications, web scraping, automating repetitive tasks, and more.

Why Learn Selenium?

🧪 Automated Testing

Test web applications automatically without manual intervention. Run regression tests, functional tests, and integration tests.

🔄 Web Scraping

Extract data from dynamic websites that load content using JavaScript.

⚡ Task Automation

Automate repetitive browser tasks like form filling, downloading files, taking screenshots, and more.

📊 Data Collection

Gather data from multiple sources for analysis, monitoring prices, tracking changes, etc.

⚙️ Installation & Setup

Step 1: Install Selenium

# Install Selenium using pip pip install selenium

Step 2: Install WebDriver

You need a browser driver (ChromeDriver for Chrome, GeckoDriver for Firefox, etc.)

# Option 1: Install webdriver-manager (Recommended - Auto-manages drivers) pip install webdriver-manager # Option 2: Download manually from: # Chrome: https://chromedriver.chromium.org/ # Firefox: https://github.com/mozilla/geckodriver/releases

Step 3: First Selenium Script

from selenium import webdriver from selenium.webdriver.chrome.service import Service from webdriver_manager.chrome import ChromeDriverManager # Setup Chrome driver automatically driver = webdriver.Chrome(service=Service(ChromeDriverManager().install())) # Open a website driver.get("https://www.python.org") # Print the title print(driver.title) # Close the browser driver.quit()
💡 Tip: Always use driver.quit() to close the browser and end the session properly. Use driver.close() to close only the current tab.

🔍 Element Locators

Locators are used to find elements on a web page. Selenium provides multiple strategies to locate elements.

8 Types of Locators

Locator Strategy Method Example
ID find_element(By.ID, "id") Most preferred, unique
Name find_element(By.NAME, "name") Good for form elements
Class Name find_element(By.CLASS_NAME, "class") Can match multiple elements
Tag Name find_element(By.TAG_NAME, "tag") Find by HTML tag
Link Text find_element(By.LINK_TEXT, "text") Exact text in link
Partial Link Text find_element(By.PARTIAL_LINK_TEXT, "text") Partial text in link
CSS Selector find_element(By.CSS_SELECTOR, "selector") Powerful and flexible
XPath find_element(By.XPATH, "xpath") Most powerful, any element

Locator Examples

from selenium import webdriver from selenium.webdriver.common.by import By driver = webdriver.Chrome() driver.get("https://www.example.com") # Find by ID element = driver.find_element(By.ID, "username") # Find by Name element = driver.find_element(By.NAME, "email") # Find by Class Name element = driver.find_element(By.CLASS_NAME, "btn-primary") # Find by Tag Name element = driver.find_element(By.TAG_NAME, "h1") # Find by Link Text element = driver.find_element(By.LINK_TEXT, "Click Here") # Find by Partial Link Text element = driver.find_element(By.PARTIAL_LINK_TEXT, "Click") # Find by CSS Selector element = driver.find_element(By.CSS_SELECTOR, "div.content > p#intro") # Find by XPath element = driver.find_element(By.XPATH, "//input[@type='submit']") # Find multiple elements elements = driver.find_elements(By.CLASS_NAME, "item") for elem in elements: print(elem.text)

CSS Selector vs XPath

CSS Selector (Faster, simpler syntax)

  • #id - Select by ID
  • .class - Select by class
  • tag.class - Tag with class
  • parent > child - Direct child
  • [attribute='value'] - By attribute

XPath (More powerful, can traverse up the DOM)

  • //tag[@id='value'] - By ID
  • //tag[@class='value'] - By class
  • //tag[text()='value'] - By text
  • //parent/child - Direct child
  • //tag[contains(@class, 'partial')] - Partial match

🖱️ Web Element Interactions

Basic Interactions

from selenium import webdriver from selenium.webdriver.common.by import By from selenium.webdriver.common.keys import Keys driver = webdriver.Chrome() driver.get("https://www.example.com") # Click an element button = driver.find_element(By.ID, "submit-btn") button.click() # Type text into input field input_field = driver.find_element(By.NAME, "search") input_field.send_keys("Selenium Python") # Clear text from input input_field.clear() # Submit a form input_field.submit() # Press Enter key input_field.send_keys(Keys.RETURN) # Get element text text = button.text print(text) # Get attribute value href = button.get_attribute("href") # Check if element is displayed if button.is_displayed(): print("Button is visible") # Check if element is enabled if button.is_enabled(): print("Button is clickable") # Check if checkbox is selected checkbox = driver.find_element(By.ID, "agree") if checkbox.is_selected(): print("Checkbox is checked")

Dropdown/Select Elements

from selenium.webdriver.support.ui import Select # Find dropdown element dropdown = Select(driver.find_element(By.ID, "country")) # Select by visible text dropdown.select_by_visible_text("United States") # Select by value attribute dropdown.select_by_value("us") # Select by index dropdown.select_by_index(1) # Get all options options = dropdown.options for option in options: print(option.text) # Deselect (for multi-select dropdowns) dropdown.deselect_all()

🚀 Advanced Selenium Features

Waits (Very Important!)

Waits help handle dynamic content that loads after the page initially loads.

from selenium.webdriver.support.ui import WebDriverWait from selenium.webdriver.support import expected_conditions as EC from selenium.webdriver.common.by import By import time # Implicit Wait (applies to all find operations) driver.implicitly_wait(10) # Wait up to 10 seconds # Explicit Wait (wait for specific condition) wait = WebDriverWait(driver, 10) element = wait.until( EC.presence_of_element_located((By.ID, "myElement")) ) # Common Expected Conditions: # - element_to_be_clickable # - presence_of_element_located # - visibility_of_element_located # - text_to_be_present_in_element # Example: Wait for element to be clickable button = wait.until( EC.element_to_be_clickable((By.ID, "submit")) ) button.click() # Hard Wait (Not recommended, use only when necessary) time.sleep(5) # Wait 5 seconds

Switching Between Windows/Tabs

# Get current window handle main_window = driver.current_window_handle # Click link that opens new tab driver.find_element(By.LINK_TEXT, "Open in New Tab").click() # Get all window handles all_windows = driver.window_handles # Switch to new window for window in all_windows: if window != main_window: driver.switch_to.window(window) break # Do something in new window print(driver.title) # Close current window driver.close() # Switch back to main window driver.switch_to.window(main_window)

Handling Frames/iFrames

# Switch to frame by index driver.switch_to.frame(0) # Switch to frame by name or ID driver.switch_to.frame("frameName") # Switch to frame by WebElement iframe = driver.find_element(By.TAG_NAME, "iframe") driver.switch_to.frame(iframe) # Switch back to main content driver.switch_to.default_content() # Switch to parent frame driver.switch_to.parent_frame()

JavaScript Execution

# Execute JavaScript driver.execute_script("alert('Hello from Selenium!');") # Scroll to bottom of page driver.execute_script("window.scrollTo(0, document.body.scrollHeight);") # Scroll to specific element element = driver.find_element(By.ID, "myElement") driver.execute_script("arguments[0].scrollIntoView();", element) # Click using JavaScript (when normal click doesn't work) driver.execute_script("arguments[0].click();", element) # Get return value from JavaScript title = driver.execute_script("return document.title;") print(title)
