📚 What is Selenium?

Selenium is a powerful open-source automation framework used to automate web browsers. It allows you to programmatically control browsers to perform tasks like testing web applications, web scraping, automating repetitive tasks, and more.

Why Learn Selenium?

🧪 Automated Testing

Test web applications automatically without manual intervention. Run regression tests, functional tests, and integration tests.

🔄 Web Scraping

Extract data from dynamic websites that load content using JavaScript.

⚡ Task Automation

Automate repetitive browser tasks like form filling, downloading files, taking screenshots, and more.

📊 Data Collection

Gather data from multiple sources for analysis, monitoring prices, tracking changes, etc.

⚙️ Installation & Setup

Step 1: Install Selenium

# Install Selenium using pip pip install selenium

Step 2: Install WebDriver Manager

WebDriver Manager automatically downloads and manages browser drivers.

# Install webdriver-manager (Recommended) pip install webdriver-manager

Step 3: First Selenium Script

from selenium import webdriver from selenium.webdriver.chrome.service import Service from webdriver_manager.chrome import ChromeDriverManager # Setup Chrome driver automatically driver = webdriver.Chrome(service=Service(ChromeDriverManager().install())) # Open a website driver.get("https://www.python.org") # Print the title print(driver.title) # Close the browser driver.quit()
💡 Tip: Always use driver.quit() to close the browser and end the session properly. Use driver.close() to close only the current tab.

🔍 Element Locators

Locators are used to find elements on a web page. Selenium provides multiple strategies to locate elements.

8 Types of Locators

Locator Strategy Method Use Case
ID find_element(By.ID, "id") Most preferred, unique
Name find_element(By.NAME, "name") Good for form elements
Class Name find_element(By.CLASS_NAME, "class") Can match multiple elements
Tag Name find_element(By.TAG_NAME, "tag") Find by HTML tag
Link Text find_element(By.LINK_TEXT, "text") Exact text in link
Partial Link Text find_element(By.PARTIAL_LINK_TEXT, "text") Partial text in link
CSS Selector find_element(By.CSS_SELECTOR, "selector") Powerful and flexible
XPath find_element(By.XPATH, "xpath") Most powerful, any element

Locator Examples

from selenium import webdriver from selenium.webdriver.common.by import By driver = webdriver.Chrome() driver.get("https://www.example.com") # Find by ID element = driver.find_element(By.ID, "username") # Find by Name element = driver.find_element(By.NAME, "email") # Find by Class Name element = driver.find_element(By.CLASS_NAME, "btn-primary") # Find by CSS Selector element = driver.find_element(By.CSS_SELECTOR, "div.content > p#intro") # Find by XPath element = driver.find_element(By.XPATH, "//input[@type='submit']") # Find multiple elements elements = driver.find_elements(By.CLASS_NAME, "item") for elem in elements: print(elem.text)

🖱️ Web Element Interactions

Basic Interactions

from selenium.webdriver.common.keys import Keys # Click an element button = driver.find_element(By.ID, "submit-btn") button.click() # Type text into input field input_field = driver.find_element(By.NAME, "search") input_field.send_keys("Selenium Python") # Clear text from input input_field.clear() # Press Enter key input_field.send_keys(Keys.RETURN) # Get element text text = button.text # Get attribute value href = button.get_attribute("href") # Check if element is displayed if button.is_displayed(): print("Button is visible")

Dropdown Elements

from selenium.webdriver.support.ui import Select # Find dropdown element dropdown = Select(driver.find_element(By.ID, "country")) # Select by visible text dropdown.select_by_visible_text("United States") # Select by value attribute dropdown.select_by_value("us") # Select by index dropdown.select_by_index(1)

Handling Alerts

from selenium.webdriver.common.alert import Alert # Switch to alert alert = Alert(driver) # Get alert text print(alert.text) # Accept alert (click OK) alert.accept() # Dismiss alert (click Cancel) # alert.dismiss()

🚀 Advanced Selenium Features

Waits (Very Important!)

from selenium.webdriver.support.ui import WebDriverWait from selenium.webdriver.support import expected_conditions as EC # Implicit Wait driver.implicitly_wait(10) # Explicit Wait wait = WebDriverWait(driver, 10) element = wait.until( EC.presence_of_element_located((By.ID, "myElement")) ) # Wait for element to be clickable button = wait.until( EC.element_to_be_clickable((By.ID, "submit")) ) button.click()

Switching Windows

# Get current window main_window = driver.current_window_handle # Get all windows all_windows = driver.window_handles # Switch to new window for window in all_windows: if window != main_window: driver.switch_to.window(window) break

Handling Frames

# Switch to frame driver.switch_to.frame("frameName") # Switch back to main content driver.switch_to.default_content()

JavaScript Execution

# Scroll to bottom driver.execute_script("window.scrollTo(0, document.body.scrollHeight);") # Click using JavaScript element = driver.find_element(By.ID, "btn") driver.execute_script("arguments[0].click();", element)

Taking Screenshots

# Full page screenshot driver.save_screenshot("page.png") # Element screenshot element = driver.find_element(By.ID, "header") element.screenshot("element.png")

Headless Mode

from selenium.webdriver.chrome.options import Options chrome_options = Options() chrome_options.add_argument("--headless") chrome_options.add_argument("--no-sandbox") driver = webdriver.Chrome(options=chrome_options)

Action Chains

from selenium.webdriver.common.action_chains import ActionChains actions = ActionChains(driver) # Hover over element element = driver.find_element(By.ID, "menu") actions.move_to_element(element).perform() # Drag and drop source = driver.find_element(By.ID, "source") target = driver.find_element(By.ID, "target") actions.drag_and_drop(source, target).perform()

📝 Complete Example: Web Scraper

from selenium import webdriver from selenium.webdriver.common.by import By from selenium.webdriver.support.ui import WebDriverWait from selenium.webdriver.support import expected_conditions as EC import pandas as pd class WebScraper: def __init__(self): self.driver = webdriver.Chrome() self.wait = WebDriverWait(self.driver, 10) def login(self, url, username, password): try: self.driver.get(url) # Wait and fill username username_field = self.wait.until( EC.presence_of_element_located((By.ID, "username")) ) username_field.send_keys(username) # Fill password password_field = self.driver.find_element(By.ID, "password") password_field.send_keys(password) # Click login login_btn = self.driver.find_element(By.XPATH, "//button[@type='submit']") login_btn.click() print("Login successful!") return True except Exception as e: print(f"Login failed: {e}") return False def scrape_data(self): data = [] try: items = self.wait.until( EC.presence_of_all_elements_located((By.CLASS_NAME, "item")) ) for item in items: title = item.find_element(By.CLASS_NAME, "title").text price = item.find_element(By.CLASS_NAME, "price").text data.append({ 'Title': title, 'Price': price }) print(f"Scraped {len(data)} items") return data except Exception as e: print(f"Scraping failed: {e}") return [] def save_to_csv(self, data, filename): df = pd.DataFrame(data) df.to_csv(filename, index=False) print(f"Data saved to {filename}") def close(self): self.driver.quit() # Usage scraper = WebScraper() data = scraper.scrape_data()
